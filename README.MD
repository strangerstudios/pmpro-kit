## Installation ##
For detailed installation steps, visit the [documentation](https://www.paidmembershipspro.com/add-ons/pmpro-quick-search-add-on/) page.

**Please ensure that once installing this version of the plugin to remove `-dev` from the plugin's folder name.**

## Contributing to Kit Add On ##
We encourage and welcome any contribution to Kit Add On. Please read the [guidelines for contributing](https://github.com/strangerstudios/paid-memberships-pro/blob/dev/.github/CONTRIBUTING.md) to this repository.

There are various **ways to the help development** of Kit Add On:

1. Report [bugs/issues](https://github.com/strangerstudios/pmpro-quick-search/issues/new) on GitHub.
2. Work on any issues by submitting a Pull Request.

Here are some ways for **non-developers to contribute** to Kit Add On:

1. Translate Kit Add On into your own [language](https://www.paidmembershipspro.com/paid-memberships-pro-in-your-language/).
2. [Purchase a paid membership](https://paidmembershipspro.com/pricing) to help fund ongoing development and bug fixes.
3. Leave an honest review for [Paid Memberships Pro - Kit Add On](https://www.paidmembershipspro.com/submit-testimonial/).
